# Dryy Android App

This repository contains an initial Android app MVP for the Dryy business concept.

## Features included
- Buyer and seller registration
- Mobile number based onboarding flow
- Terms and conditions consent
- Role selection (Buyer / Seller)
- Product marketplace demo cards
- Solar drying and food waste theme design
- Registration flow for ₹99

## Tech stack
- Kotlin
- Jetpack Compose
- Material 3
- Android SDK 34

## How to open in Android Studio
1. Open Android Studio.
2. Choose "Open" and select this folder.
3. Let Gradle sync complete.
4. Run the app on an emulator or device.
